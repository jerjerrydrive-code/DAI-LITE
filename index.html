Endpoint blocked by CORS? Known fixes

Browsers only allow cross-origin API calls when the server sends CORS headers. OpenRouter and NVIDIA already do, so their presets work as-is. If a request fails:

  • Ollama (local): start it so it allows this page's origin — OLLAMA_ORIGINS=* ollama serve (or set OLLAMA_ORIGINS to your exact origin).
  • Any endpoint without CORS headers: run a throwaway Chrome — chrome --disable-web-security --user-data-dir=/tmp/dai — or put a tiny local proxy in front that adds Access-Control-Allow-Origin, then point the Base URL at the proxy.

This app controls real RF and hardware. DAI-LITE can command a physical Flipper Zero to transmit radio signals, emulate access credentials, run scripts, and modify files. Transmitting on certain frequencies, cloning cards, or accessing systems you don't own may be illegal.
